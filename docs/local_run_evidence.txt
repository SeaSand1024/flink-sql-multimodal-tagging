**Why this demonstrates text/image complementarity (e2):** text recall alone
returns only `智能穿戴`; the image recall adds `数码家电`; the Stage-2 judge
merges both → `{"labels":["智能穿戴","数码家电"]}`. Neither modality alone
would produce both labels; the multimodal judge on the candidate union is what
finds `数码家电`.

**Gap:** these are deterministic local stubs, not real `qwen3-vl-embedding` /
`qwen3.6-plus` inference. Real multimodal output requires the Alibaba Cloud
Realtime Compute Flink (VVR 11.9 Preview 2+) cluster with those models
provisioned + the Milvus `product_label` collection seeded (`labels/labels.sql`).
